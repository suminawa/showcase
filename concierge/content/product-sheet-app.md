# スプレッドシート業務アプリ キット

定価 9,800 円。発売前です。発売日は決まりしだい、作品ページと note でお知らせします。Google スプレッドシートの「定義」シートに列を書くだけで、顧客・案件・在庫などの一覧・検索・登録・編集・CSV 出力の画面を、スプレッドシートから Web アプリとして公開できます。だれが見られるかはシートの共有設定のままで、サーバーは要りません。AI による絞り込みと要約は任意で、使う場合は Claude API のキーをお客さまご自身で設定します。作品ページで見本を試せます。
