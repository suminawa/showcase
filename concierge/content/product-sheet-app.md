# スプレッドシート業務アプリ キット

定価 9,800 円。2026 年 9 月 22 日に発売し、9 月 25 日に 1.1、10 月 10 日に 1.1.2 を出しました。10 月 17 日から定価を 9,800 円にしました。1.x をお求めの方は無料で最新版に更新できます（BOOTH は購入履歴から、note は記事の添付から）。note の有料記事と BOOTH で販売しています。Google スプレッドシートの「定義」シートに列を書くだけで、顧客・案件・在庫などの一覧・検索・登録・編集・CSV 出力の画面を、スプレッドシートから Web アプリとして公開できます。だれが見られるかはシートの共有設定のままで、サーバーは要りません。1.1 から、LINE・Slack・Discord への通知と、LINE でお一人ずつに送る機能が入りました。AI による絞り込みと要約は任意で、使う場合は Claude API のキーをお客さまご自身で設定します。作品ページで見本を試せます。

1.1.2 で変わったところ: シートをコピーしても台帳 ID で正しく開け、同時に更新したときは古い内容での保存を止めて読み直しをご案内します。Webhook URL と LINE のトークンはスクリプトプロパティに移せます。LINE の友だちの自動取得は、同梱の Cloudflare Worker の中継を通す形になりました（Cloudflare のアカウントと Node.js が要ります。直接の受信は使えません）。上げ方は README の 12 章にあります。
