# AI 書類読み取りキット

定価 16,800 円。発売前です。発売日は決まりしだい、作品ページと note でお知らせします。請求書・領収書・名刺などの PDF や写真を読み取り、確認画面で直してから CSV やスプレッドシートに出すキットです。読み取る項目は帳票ごとの型（JSON）で決められ、読めなかった項目は確認画面で色が付きます。Next.js のテンプレートが入っていて、Claude API のキーはお客さまご自身のものを設定します。作品ページで見本を試せます。
