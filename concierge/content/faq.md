# よくあるご質問

## この LINE の返事は誰が書いていますか

公開している資料の範囲で、AI がお答えしています。資料に無いことは「載っていません」とお答えします。担当者と話したいときは「担当者」と送ってください。人が 24 時間以内にお返事します（土日も見ています）。

## 支払い方法は何がありますか

キットは、note の有料記事はクレジットカードなど note の決済手段、BOOTH は BOOTH の決済手段（クレジットカード・コンビニ払いなど）が使えます。ご依頼は、ココナラ・ランサーズの各サービスの決済か、直接のご依頼なら銀行振込か請求書払いです。

## インボイス（適格請求書）は出せますか

適格請求書（インボイス）の登録番号はありません。請求書は税込の額でお出しします。

## 買ったあとの更新はどうなりますか

1.x の更新は無料です。BOOTH はファイルの差し替え、note は記事の追記でお渡しします。

## 返金はできますか

デジタル商品のため、購入後の返金はお受けしていません。ご購入から 14 日間は、手順書どおりに動かないときにメールで設置まで一緒に確かめます。

## 法人でも使えますか

使えます。組織ライセンスでは同じ組織内の複数のサイトや業務で使えます。再配布や、同種の商品としての販売はできません。

## AI 案内窓口キットの API 費用は誰が払いますか

Claude API の利用料は、お客さまご自身の API キーに対して発生します。質問 1 回あたりの費用の目安は 1 円から十数円で、文書の量によって変わります。キットには 1 日の質問数の上限を設ける仕組みが入っているので、上限で費用を抑えられます。

## 納期はどれくらいですか

キットはご購入後すぐにお使いいただけます。既製キットの設置は 3 日ほど、個別の開発は 7 日ほど、サイト制作や AI 窓口の設置は 10〜14 日ほどが目安です。お支払いと資料がそろった日から数えます。着手できる時期は、その時点の受注状況によります。

## 返信の目安を教えてください

LINE のトークには 24 時間以内にお返事します（土日も見ています）。メールとトークルームは 3 営業日以内、多くの場合は 1 営業日以内です。

## 打ち合わせはできますか

やり取りはメッセージで進めます。ビデオ通話や電話は行っていません。

## 修正は何回までできますか

修正の回数は、お見積もりに明記します。既製キットの設置は修正 1 回、AI 窓口や間取りの設置は修正 2 回が目安です。

## 秘密保持の契約は結べますか

ご相談に応じます。必要なときは、最初のご連絡でお知らせください。

## 見本のサイトに載っている会社は実在しますか

実在しません。業種別のサイト見本と AI 窓口の見本の文書は、すべて架空の会社です。実在の会社名・住所・電話番号は使っていません。
