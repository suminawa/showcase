# よくあるご質問

## 支払い方法は何がありますか

note の有料記事はクレジットカードなど note の決済手段、BOOTH は BOOTH の決済手段（クレジットカード・コンビニ払いなど）が使えます。受託のご依頼は、ココナラ・Lancers・Fiverr の各サービスの決済か、銀行振込です。

## 買ったあとの更新はどうなりますか

1.x の更新は無料です。BOOTH はファイルの差し替え、note は記事の追記でお渡しします。

## 返金はできますか

デジタルデータの性質上、購入後の返金はお受けしていません。動作しない不具合があった場合は、納品後 14 日間は無償で対応します。

## 法人でも使えますか

使えます。組織ライセンスでは同じ組織内の複数のサイトで使えます。再配布や、同種の商品としての販売はできません。

## AI 案内窓口キットの API 費用は誰が払いますか

Claude API の利用料は、お客さまご自身の API キーに対して発生します。質問 1 回あたりの費用の目安は数円から十数円で、文書の量によって変わります。キットには 1 日の質問数の上限を設ける仕組みが入っているので、上限で費用を抑えられます。

## 納期はどれくらいですか

既製キットの導入は 3 日、個別の開発は 7 日、サイト制作や AI 窓口の設置は 10 日から 14 日が目安です。着手できる時期は、その時点の受注状況によります。

## 対応時間と返信の目安を教えてください

平日・土日とも対応しています。お問い合わせには 3 営業日以内、多くの場合は 1 営業日以内に返信します。

## 見本のサイトに載っている会社は実在しますか

実在しません。業種別のサイト見本と AI 窓口の見本の文書は、すべて架空の会社です。実在の会社名・住所・電話番号は使っていません。
