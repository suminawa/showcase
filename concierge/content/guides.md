# 悩みから読む

受注サイトで繰り返し出ている悩みを 1 つずつ取り上げ、手で解く手順と見本をまとめたページです。

## PDF の請求書をスプレッドシートに手で書き写す作業を減らす

請求書の PDF から請求元・日付・金額をスプレッドシートに移す手間を減らす方法をまとめています（https://suminawa.dev/guides/pdf-to-spreadsheet ）。手で行うなら、写す項目を 1 行目に並べ、日付と金額の書き方をそろえる列と「税抜 + 消費税 = 合計」の検算列を足すと、確かめる行が 30 行から 2〜3 行に減ります。AI に読ませる場合は、見たままの文字と根拠と確かさだけを返させ、変換と検算はプログラムで行うのが安全です。詳しい手順は note の記事、Claude API での実装は Zenn の記事にあります。そのまま使える形にしたものが AI 書類読み取りキット（定価 16,800 円）で、見本は https://suminawa.dev/projects/doc-reader で試せます。

## 顧客管理のスプレッドシートが、いつの間にか崩れていく

お客さまの一覧を表で持ったまま、入力の揺れ・重複・上書きを防ぐ方法をまとめています（https://suminawa.dev/guides/customer-sheet ）。手で行うなら、左端に ID の列を作り、状態や担当者は入力規則のプルダウンに、電話番号は書式なしテキストにして、更新日時と重複を見る列を足します。画面を足すなら、保存のときに更新日時を照合して上書きを止め、削除は別シートに残します。そのまま使える形にしたものがスプレッドシート業務アプリ キット（定価 12,800 円）で、見本は https://suminawa.dev/projects/sheet-app で試せます。

## LINE 公式アカウントの問い合わせに、自社の資料だけで答えさせる

LINE 公式アカウントに同じ質問が何度も届くときの対処をまとめています（https://suminawa.dev/guides/line-auto-reply ）。標準の機能なら、あいさつメッセージとリッチメニューで質問の入口を見せ、キーワード応答には表記ゆれの言葉も登録します。AI に答えさせる場合は、自社の文書だけを根拠にして根拠の URL を添え、資料に無いことは担当者へ引き継ぐ形にします。そのまま使える形にしたものが LINE 案内窓口キット（定価 12,800 円）で、答え方は https://suminawa.dev/projects/ai-concierge の見本で試せます。

## 電話と LINE で受けている予約を、空いている時間から選んでもらう

電話と LINE に分かれた予約の受付を 1 つにまとめる方法をまとめています（https://suminawa.dev/guides/booking-page ）。手で行うなら、受け付ける枠を曜日・開始・終了・間隔・定員の決まりにし、台帳を 1 つにして電話でも LINE でも返事の前に書き、確認の文面にキャンセルの締切を入れ、前日のリマインドは時刻を決めてまとめて送ります。仕組みにするなら、最後の 1 枠は書き込む直前に数え直し、同じ枠に 2 人が入らないようにします。そのまま使える形にしたものが予約ページ キット（定価 7,980 円）で、見本は https://suminawa.dev/projects/booking で試せます。

## 毎月の売上の集計とグラフを、スプレッドシートで手で作り直している

月例の集計表とグラフを毎月作り直す手間を減らす方法をまとめています（https://suminawa.dev/guides/monthly-sales-report ）。手で行うなら、生データを 1 シートに 1 行 1 取引で置いて日付を 2026-09-19 の形にそろえ、集計は別のシートで範囲を列ごと（A:A）に指定します。先月比は同じ日数どうしで比べ、目標は「月・目標額」の表から当月の行だけを引き、数として読めない行は数えて横に出します。仕組みにするなら、集計の決まりを 1 か所に書いて、数字・折れ線・棒・目標・表の 1 枚の画面にします。そのまま使える形にしたものがダッシュボード キット（定価 9,800 円）で、見本は https://suminawa.dev/projects/dashboard で試せます。

## 問い合わせのメールが埋もれて、返信が遅れたり漏れたりする

見積もり依頼・クレーム・営業が同じ受信箱に混ざるときの対処をまとめています（https://suminawa.dev/guides/inbox-triage ）。手で行うなら、Gmail に「見積もり」「質問」「クレーム」「予約・日程」「請求・支払い」「営業・勧誘」のラベルを作ってフィルタで付け、返したメールは既読ではなく「済」のラベルを付けてアーカイブします。スプレッドシートに 1 通 1 行の台帳（受信日・差出人・分類・状態・担当・期限）を作り、担当を書くと「どちらかが返したはず」が無くなります。仕組みにするなら、15 分ごとに新着を読んで分類・緊急度・要約をシートに書き、期限が近いものやクレームを通知の先頭に出し、返信は下書きまでにして送るのは人にします。そのまま使える形にしたものが AI 問い合わせ整理キット（定価 5,980 円）で、見本は https://suminawa.dev/projects/inbox-triage で読めます。

## 契約の更新や点検の期限を、スプレッドシートに書いたまま見落とす

車検・賃貸契約・ドメイン・資格の更新期限を表に並べたまま見落とすときの対処をまとめています（https://suminawa.dev/guides/deadline-alert ）。手で行うなら、期限シートの列を「件名・期限・担当・状態」の 4 つにし、期限は文字列ではなく日付型で入れます。条件付き書式で 30 日以内は黄色、7 日以内はオレンジ、超過は赤にし、更新が済んだ行は消さずに「完了」と書いてフィルタで外します。車検のように準備が要るものは、何日前に知らせるかを件ごとに決め、スプレッドシートのタイムゾーンは東京にします。仕組みにするなら、毎朝 8 時に 1 回、超過・今日・数日前の順に 1 通にまとめて Slack か Discord へ送り、「完了」の行は飛ばします。そのまま使える形にしたものが期限アラート GAS キット（定価 2,980 円）で、見本は https://suminawa.dev/projects/deadline で試せます。

## Googleフォームの自由記述を集計する｜お客様の声から改善を一つ決める

アンケートの自由記述を上から読むだけで終わってしまうときの対処をまとめています（https://suminawa.dev/guides/survey-free-text）。集計する期間を決めて元の回答を別のタブに写し、1 つの回答に主な分類を 1 つ付けて数え、件数と原文を見比べて、次に試すことを 1 つ決める手順です。手順は無料の note の記事（https://note.com/suminawa/n/ne4f938f8fcd4）で最後まで行えます。分類と集計を毎回続けたい場合は、お客さまアンケート キット（7,980 円の買い切り。初期設定はご自身で行い、AI の利用料は別にかかります）があります。

## LPの構成を自分で決める｜載せる内容と順番を1枚の表に書き出す

広告や新しいサービスのために 1 枚のページ（LP）を用意したいのに、何をどの順で載せるかが決まらないときの対処をまとめています（https://suminawa.dev/guides/lp-structure ）。先に「誰に・何をしてほしいか・どこから来るか」の 3 つを決め、スプレッドシートか文書に、最初の画面・困りごと・できること・料金の目安・流れ・よくある質問・問い合わせの 7 つの段を上から順に書き出します。書いた表は、制作を頼むときの原稿にも、自分で作るときの下書きにもなります。手順は無料の note の記事（https://note.com/suminawa/n/n10a6e8fbcbfd ）で最後まで行えます。書いた内容をページにする土台が欲しい場合は、業種別 LP テンプレ パック（6,980 円の買い切り。書き換えと公開はご自身で行い、サーバーやドメインの費用は別にかかります）があり、見本は https://suminawa.dev/sites で見られます。

## PDF の表を Excel やスプレッドシートに移すと、列が崩れる

PDF の注文明細や一覧をコピーして Excel やスプレッドシートに貼ると、1 つのセルに詰まったり行がずれたりするときの対処をまとめています（https://suminawa.dev/guides/pdf-table-to-excel ）。先に表の文字をドラッグで選べるか（選べないスキャンの PDF は OCR が先に要る）を見分け、Windows の Microsoft 365 の Excel なら「データ」→「データの取得」→「ファイルから」→「PDF から」で、Mac やスプレッドシートなら PDF を Word で開いて表にしてから貼ります。取り込んだあとは、2 ページ目の見出しの行・ページをまたいで割れた行・文字のままの数字を直し、金額の合計と行数を PDF と突き合わせます。手順は無料の note の記事（https://note.com/suminawa/n/neeaf12edf05f ）で最後まで行えます。請求書や注文書を 1 枚ずつ、明細まで確認しながら表にしたい場合は、AI 書類読み取りキット（16,800 円の買い切り。設定はご自身で行い、読んだ枚数ぶんの API 費用が別にかかります）があります。何十ページもある報告書の表を丸ごと移す用途には作っていません。

## LINE 公式アカウントのあいさつ・自動応答・リッチメニューを、初期のまま止めない

LINE 公式アカウントを作ったまま、友だち追加のあいさつが初期の「最新情報を定期的に配信」で、何を送っても「個別のお問い合わせを受け付けておりません」と返るときの対処をまとめています（https://suminawa.dev/guides/line-official-setup ）。LINE 公式アカウント Manager の「応答設定」でチャットと応答メッセージを両方オンにし、あいさつメッセージを「何を送るアカウントか・次にしてほしいこと・返事の目安」の順に書き換えます。リッチメニューは大（2500×1686）の 6 分割にし、ページを開かせるものはリンク、LINE の中で答えるものはテキスト動作にします。キーワード応答は完全一致なので、1 つの返答に言い換えを並べ、どれにも当たらないときの一律応答も受け付けの文に書き換えます。手順は無料の note の記事（https://note.com/suminawa/n/nb152a484b12a ）で最後まで行えます。言い換えを含む自由な質問に自社の文書の範囲で AI に答えさせたい場合は、LINE 案内窓口キット（12,800 円の買い切り。Messaging API・置き場所・API の鍵の用意はご自身で行い、API の利用料が別にかかります）があります。
