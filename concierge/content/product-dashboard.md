# ダッシュボード キット

発売前です。価格と発売日は、作品ページと note でお知らせします。スプレッドシートや CSV にたまった売上・予約・お問い合わせの数字を、設定を書くだけで KPI・折れ線・棒・目標・表の並んだ 1 枚の画面にするキットです。置き方は 3 通りで、自分のサイトに貼る形、Next.js のページに組み込む形、Google スプレッドシートからウェブアプリとして公開する形が 1 つの zip に入っています。画面の上の絞り込み（期間と、列ごとに 3 つまで）を変えると、下の部品がすべて同時に変わります。どのグラフにも「表で見る」の切り替えと CSV の書き出しがあり、日本語と英語、明るい配色と暗い配色に対応します。外部の API を使わないので、使うほど増える費用はありません。円グラフ、2 軸のグラフ、地図、ログイン、AI による要約は入っていません。作品ページで見本を試せます。
